
# openh264
This is for the openh264 codec, which is used for H.264 video encoding and decoding.
Download and unzip the http://ciscobinary.openh264.org/openh264-1.8.0-win64.dll.bz2
and paste it into the directory specified in the path. (ex= c:\windows\system32\ )
It will be version checked, so it must be that version.
